行为和原版是否一致

这里说的“一致”指什么：同样的输入下，重写后的代码表现是不是和原版一样。衡量办法是拿 tqdm 作者自己写的那套测试去跑重写后的代码。 这些测试是照着原版的行为写的，每个测试都在说“给这个输入，应该得到这个结果”；能通过，就说明在测试覆盖到的地方表现一致。 例如原版测试要求 format_interval(-1) 返回 '-00:01'：这次的交付物返回的就是它，11-15 那版返回 '-1:59:59'。

这些数是怎么得到的

  • 测试：把原版 9cf5a12 的测试目录原样拿来，配上各版本的 tqdm/ 包，在同一个测试环境（Python 3.11.16）里逐个文件运行，运行时不联网。性能测试文件没有跑。
  • 结构：用 Python 的语法树统计行数、函数和类；函数长度不含 docstring。圈复杂度和可维护性指数用 radon，静态检查用 ruff（未用项目自己的配置，规则是未使用和未定义的名字、常见错误写法、可简化的写法）。
  • 公开接口：在各版本上逐个导入原版的 30 个模块做运行时比对。原版自己有两个模块在这个环境里导入不了（一个已损坏的废弃别名，一个需要 keras），不计入。命令行入口模块没有导入。
  • 文档比例、token、相同行、重复度：取自各次作业自己的代码质量记录；上次实验的取自它的公开报告。
